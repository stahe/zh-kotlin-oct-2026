    15. 附录

    15.1. 使用 Laragon 的 MySQL 数据库管理系统

    本文第 10 章和第 11 章使用 MySQL 8 数据库管理系统（DBMS）。在 Windows 上安装它最简单的方法是安装 Laragon，这是一个便携式开发环境，包含 MySQL、图形客户端 HeidiSQL、已配置好的终端、Apache 和 PHP。作者在他的 PHP 课程中也使用它。

    15.1.1. 安装

    Laragon 可从以下地址下载： https://laragon.org。安装是标准的；可以使用建议的安装文件夹（[C:\laragon]）。Laragon 提供 MySQL 8（具体版本取决于 Laragon 的版本），带有一个 [root] 管理员账户，该账户没有密码 ，并有一个在本机上监听端口 3306 的服务器。这就是文档中示例所假定的配置，其中 JDBC URL 的形式为：

    1
    jdbc:mysql://localhost:3306/dbarticles

    用户名为 [root] ，密码为空。如果 MySQL 是以其他方式安装的，为 [root] 设置了密码，就必须相应地修改示例（[.properties] 文件或程序顶部的常量）。

    对于没有 Laragon 的系统，你也可以从 https://dev.mysql.com/downloads/mysql/ 安装 MySQL Community Server，或者安装其开源衍生版本 MariaDB。不过，这些示例只在 MySQL 8 上测试过：第 10 章的脚本使用了 MySQL 8 特有的排序规则（[utf8mb4_0900_ai_ci]），在 MariaDB 上需要对其进行调整，JDBC 驱动程序也是如此（MariaDB 提供自己的驱动程序）。

    15.1.2. 启动和停止 MySQL

    Laragon 主窗口中有一个启动服务器（Apache 和 MySQL）的 “Start All” 按钮，以及一个停止它们的 “Stop” 按钮。MySQL 不是在系统启动时运行的 Windows 服务：它只在从 Laragon 启动时才运行，这可以避免它在不使用时占用资源。Laragon 菜单（在窗口中右键单击）还允许你只启动 MySQL 并选择它的版本。

    当 MySQL 没有运行时，第 10 章和第 11 章的程序会因 JDBC 驱动程序抛出的异常而失败，该异常表明无法建立连接（[CommunicationsException]：“Communications link failure”）：出现错误时，这是首先要检查的事项。

    15.1.3. 命令行客户端

    Laragon 的 Terminal 按钮会打开一个终端，在其中可以使用 Laragon 的命令，包括 MySQL 命令行客户端（[mysql]）。要连接到服务器，请使用：

    1
    > mysql -u root

    然后输入 SQL 命令，每条命令以分号结尾（[show databases;]、[use dbarticles;]、[select * from articles;]），并用 [exit] 退出。该客户端还可以运行 SQL 脚本，第 10 章就是这样创建其数据库的：

    1
2
3
    > cd kotlin-oct-2026\10-jdbc\sql
> mysql -u root < dbarticles.sql
> mysql -u root < dbtaxes.sql

    这些脚本每次运行时都会完全重新创建其数据库：测试之后，你可以重新运行它们，把数据恢复到初始状态。

    15.1.4. HeidiSQL 图形客户端

    Laragon 的 Database 按钮会启动图形客户端 HeidiSQL。首次启动时，HeidiSQL 会提供一个已为 Laragon 的 MySQL 服务器配置好的连接会话（主机 [127.0.0.1]，用户 [root]，空密码，端口 3306）；只需打开它即可。你将看到：

    • 左侧是服务器的数据库及其表的树形视图；
    • 右侧是若干选项卡，显示表的结构、表的数据（可以直接编辑），以及用于输入 SQL 查询的字段（“Query”选项卡），这些查询通过 [F9] 执行。

    要使用第 10 章的脚本创建数据库，请在查询选项卡中打开该脚本（通过“文件”菜单，使用加载 SQL 文件的命令），然后执行它（[F9]）。你也可以使用 HeidiSQL 的菜单创建数据库、用户和用户权限（右键单击连接 /“新建”/“数据库”；“工具”菜单 /“用户管理器”），但 SQL 脚本的优点是可重现，并且可以重新运行。

    IntelliJ IDEA 也可以通过其“Database”窗口连接到数据库：在那里你可以查看表及其数据，并且无需离开 IDE 就能执行 SQL 查询。

    15.1.5. 本文中的数据库

    第 10 章和第 11 章使用下列数据库，它们都位于本地 MySQL 服务器上：

    数据库
    章节
    创建方式

    [dbtaxes]
    10

    测试完成后，可以使用 SQL 命令 [drop database name;] 删除数据库，在 [mysql] 客户端或 HeidiSQL 中均可。
