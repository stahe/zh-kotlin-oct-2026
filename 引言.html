    1.1. 2011 年至 2026 年的 Kotlin

    Kotlin 由 JetBrains公司于 2011 年 7 月推出，该公司是 IDE IntelliJ IDEA 的发行商，当时正在寻找一门比 Java 更简洁、更安全、同时又与之兼容的语言，用来编写自己的工具：Kotlin 程序被编译为 字节码，由 Java 虚拟机 （JVM）执行，既可以调用 Java 代码，也可以被 Java 代码调用。其名称来自芬兰湾中靠近圣彼得堡的一座岛屿，设计它的团队曾在那里工作。

    主要里程碑：

    • 2016 年：Kotlin 1.0，第一个稳定版本，并附带兼容性承诺；
    • 2017 年：Google 宣布官方支持使用 Kotlin 开发 Android 应用；2019 年，Android 变为“Kotlin 优先”：Kotlin 成为新 Android 应用的推荐语言；
    • 2018 年：Kotlin 1.3，使 协程趋于稳定，这是 Kotlin 对异步编程的解答（第 9 章）；
    • 该语言由 JetBrains 开发；Kotlin 基金会由 JetBrains 和 Google 于 2017 年创立，负责监督其演进，每个阶段都要经过公开提案（“KEEP”，Kotlin Evolution and Enhancement Process）；
    • 2024 年：Kotlin 2.0，带来名为 K2的新编译器，它更快，并且在跟踪代码中的类型（智能类型转换）方面更出色；
    • Kotlin 也面向 JVM 以外的平台：JavaScript、WebAssembly 和原生代码（Kotlin/Native，iOS）。本文档只涉及 JVM 上的 Kotlin；
    • 自 2.0 版起，大约每六个月发布一个 新的语言版本 （2.1.0、2.2.0、2.3.0、2.4.0……）；在两者之间，工具版本 （2.x.20）会在不改变语言的情况下改进工具和标准库。本文档使用 2026 年 9 月发布的 2.4.20 版。新特性通常先作为 实验性特性引入；必须显式启用它们（通过编译器选项或 [@OptIn] 注解），之后才会在后续版本中变得稳定。

    每个小程序都是一个 Kotlin 文件，存放在以其命名的包中（[src/main/kotlin/basics04/Basics04.kt], package [basics04]）。你可以在 IntelliJ IDEA 中点击其 [main] 函数旁边的绿色三角形来运行它，也可以通过 Gradle 在命令行中运行（[gradlew -q run -Pmain=basics04.Basics04Kt]，第 2 章）。需要外部库的程序（Jackson、JUnit、Spring、MySQL 驱动、Hibernate、Spring Boot）必须在项目的 [build.gradle.kts] 文件中声明它：Gradle 会在第一次构建时从 Maven Central 仓库下载它。

    本文档中的所有程序都已由 Kotlin 2.4.20 编译器编译，没有错误或警告，编译时使用了将所有警告视为错误的选项（[allWarningsAsErrors]），然后在 JDK 25 上运行。本文档中重现的结果就来自这些运行。第 2 章到第 4 章的结果是在法语语言和国家设置（fr-FR）下得到的，就像在法语版 Windows 机器上一样：格式化的浮点数以小数逗号显示，日期也是法语的；后续章节的结果是在英语设置下得到的。两点说明：

    • Kotlin 编译器和 JDK 的错误消息（异常消息）是英文的：它们没有法语翻译；
    • 示例是在 Linux 上运行的。在大多数情况下这没有区别：JVM 上的 Kotlin 是跨平台的。少数差异（用 / 而不是 \ 的文件路径、终端命令、用 [./gradlew] 代替 [gradlew]）会在出现的地方加以说明。

    多线程、异步或网络程序的结果，以及测得的时长，可能每次运行都有所不同：注释着重说明可重现的内容。
